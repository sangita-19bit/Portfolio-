# Sangita Portfolio

Static personal portfolio site for an AI UI Designer, ready to deploy on Vercel.

## Run locally

Because this is a static site, you can preview it with any simple local server.

```powershell
npx serve .
```

## Deploy on Vercel

1. Import this folder into Vercel.
2. Framework preset: `Other`.
3. Build command: leave empty.
4. Output directory: leave empty.
5. Deploy.

## Customize

- Update content in `index.html`
- Adjust styling in `styles.css`
- Replace the email CTA in `index.html` with your real contact details
