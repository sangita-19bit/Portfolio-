## Architecture & Features

- **3D Liquid Particle Sculpture Hero**: Interactive particle simulation rendered with responsive touch/cursor physics.
- **Project Archives Drawer**: Procedural fluid art glass folder showcase powered by Framer Motion shared-layout (`layoutId`) animations.
  - **RentFlow**: Online property rental & tenant management ecosystem.
  - **BlinkExam**: Online examination engine with automated scoring algorithms and timed attempts.
  - **Swan Botanics**: Luxury botanical e-commerce storefront with dynamic category filtering.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sangita-19bit/Portfolio-.git

# Navigate to project directory
cd Portfolio-

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```
